## Что приложить к письму

**1. Скриншот DNS-зоны.** Plesk → домен `silkroadtech.kz` → вкладка «Хостинг и DNS» → **DNS**. Снимок должен захватить строки:

```
silkroadtech.kz.      A       195.210.46.64
silkroadtech.kz.      AAAA    2a00:5da0:1000::134
silkroadtech.kz.      NS      ns1.ps.kz. / ns2.ps.kz. / ns3.ps.kz.
```

**2. Файл `dns-evidence.txt`** — рядом с этим документом. Данные whois по IP-адресу подтверждают принадлежность сети Казахстану; там же зафиксирован прежний адрес Vercel (US) как исходное состояние нарушения.

## После восстановления делегирования

1. Домен начнёт резолвиться публично — обычно в течение нескольких часов.
2. В Plesk выпустить SSL-сертификат Let's Encrypt. Раньше выпуск падал с ошибкой
   `NXDOMAIN looking up A` — именно из-за снятого делегирования; других препятствий нет.
3. Проверить сайт по списку в `DEPLOY.md`.

**Важно:** не переключать A-запись обратно на Vercel ни при каких обстоятельствах — это повторит то самое нарушение, за которое домен заблокировали.
